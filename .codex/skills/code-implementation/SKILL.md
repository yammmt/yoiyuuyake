# コード実装ガイド

コードを実装する際の規約を記します。

## 作業ブランチ

`main` ブランチには、特別な指示がない限りは、変更をコミットしません。

作業を開始する際に現在のブランチを確認します。
現在のブランチが作業用ブランチでない場合は、`main` から作業ブランチを新規作成してチェックアウトします。
すでに当該作業用のブランチにいる場合は、そのブランチで作業を継続します。

ブランチ名は、issue 番号がある場合は `feature/<issue番号>-<作業目的の概要>`、ない場合は `feature/<作業目的の概要>` とします。
例えば、`feature/5-weather-scores` または `feature/code-review` とします。

この命名規則は非本質であり、人間の判断で改名される場合があります。

## コミットの粒度

変更は意味単位ごとに、最小単位でコミットします。

## コミット後の修正

作業ブランチ上のコミットに対して、なんらかの指摘を受けて修正を行う場合、それは `fixup` コミットとします。
