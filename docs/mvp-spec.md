# Yūyake Finder MVP仕様

## 1. この文書の位置付け

この文書は、Yūyake Finderの最初の実装における正本である。実装エージェントは、実装前に必ず本書を読み、ここに書かれていない機能を追加しない。

将来の構想は [requirements.md](requirements.md) に記録している。本MVPは、その構想のうち「指定地点における、今日の夕焼け予報」を検証するための意図的に小さい範囲である。

## 2. 目的

ユーザーが日本国内の任意の地点を指定すると、その地点における**今日の夕焼けの気象的な期待**と、**地形上の西空の見晴らし**を確認できる。

MVPの成功条件は、ユーザーが次の二点を数秒で判断できることである。

1. 今夜は、透明感のあるグラデーションまたは高彩度の赤焼けを期待できそうか。
2. 山・丘などの地形によって、日没方向が早く隠れそうか。

## 3. 対象範囲

### 対象

- 日本国内の任意地点
- 今日の日没に限る
- 地点は、地図クリックまたは地名・施設名・住所の検索で指定する
- 日没時刻、見頃の時間帯、`Gradient`、`Dramatic`、地形上の西空の視界を表示する
- 地形は国土地理院の数値標高モデル（DEM）を用いる
- 天気予報はOpen-Meteoを用いる

### 明確な非対象

- 明日以降の予報
- 現在地の取得
- 徒歩・自転車・車の経路、所要時間、到達圏
- 行ける候補地点の提案
- 建物、樹木、工事中の構造物による遮蔽
- PLATEAU、OpenStreetMap、建物高さデータの利用
- アカウント、保存、お気に入り、通知、写真投稿
- 夕焼けの現地観測・機械学習による精度改善

非対象の機能は、コード上でも将来拡張のための空のUIとして表示しない。

## 4. ユーザー操作と画面

1. ユーザーは検索欄で場所を選ぶ、または地図をクリックする。
2. 選択地点の緯度・経度を確定する。
3. 今日の日没時刻、気象スコア、地形上の見晴らしを表示する。

### 入力

- Google Maps Platformを利用し、地図表示と地点選択を提供する。
- 地名・施設名・住所の入力にはPlace Autocompleteを使う。
- 選択結果として少なくとも地点名、緯度、経度を取得する。
- 地図クリック時は逆ジオコーディングで地点名または住所を表示してよい。

### 出力

- 選択地点名
- 今日の日没時刻
- 見頃の目安（例: 日没20分前から日没後25分）
- `Gradient` スコア: 0〜100
- `Dramatic` スコア: 0〜100
- 地形上の西空の視界: `広い` / `一部遮られる` / `遮られやすい`
- 地形による補足文

画面には必ず次の注意書きを表示する。

> 見晴らしは地形を考慮した推定です。建物・樹木などの遮蔽物は考慮していません。

## 5. 夕焼け予報

### データ源

Open-Meteo Forecast APIを使用する。日没前後の時間別データとして、少なくとも次を取得する。

- 低層雲量
- 中層雲量
- 高層雲量
- 総雲量
- 視程
- 相対湿度
- 降水量または降水確率
- 風速

気象モデルは、Open-Meteoで日本向けに利用できるJMA系モデルを優先候補とする。ただし、モデル指定やフォールバックの実装詳細はAPIの当時の仕様に従う。

### スコア

予報を単一の総合点に集約せず、二種類を並列で表示する。

| スコア | 意味 | 主な正の要因 |
| --- | --- | --- |
| `Gradient` | 雲が少なく、橙・紫のなめらかなグラデーションが出る期待 | 低層雲が少ない、視程が良い、降水がない |
| `Dramatic` | 赤・桃・紫の高彩度な焼け空が出る期待 | 中層・高層雲が適量、日没前後に雲が残る |

スコアの初期版は説明可能なルールベースとする。係数の最適化や機械学習はMVPに含めない。雲量が少ないことは`Gradient`には有利でも、`Dramatic`には常に有利ではない。

UIでは、次の表現を使う。

- `Gradient`: 青紫・桃・橙の淡いグラデーションカード
- `Dramatic`: 紫・赤・橙の濃いグラデーションカード

## 6. 地形上の見晴らし

### データ源

国土地理院の数値標高モデル（DEM）を利用する。DEMはアプリの実行時に外部から取得せず、必要な範囲を事前に取り込み、地形計算用に整形して保持する。

### 判定方法

1. 指定地点の当日の日没方位と、日没前後の太陽高度を天文計算で求める。
2. 日没方位の前後およそ15〜25度について、地点から外側へ複数本のレイを飛ばす。
3. 各レイ上のDEM標高から、地点から見た地形の見上げ角を求める。
4. 最大の地形見上げ角と太陽高度を比較し、日没直前の太陽が地形で隠れる可能性を求める。
5. 結果を三段階の地形視界と補足文に変換する。

概念式:

```text
地形見上げ角 = max(atan2(地点より高い地面の高さ, 地点からの距離))
```

### 表示上の意味

- `広い`: 日没方位の地形による遮蔽が小さい
- `一部遮られる`: 地形により夕日そのものが早く隠れる可能性がある
- `遮られやすい`: 山・丘・尾根により日没方向の低空が大きく隠れる

日没後の上空の色は、太陽そのものが隠れた後も観賞できる。このため「夕日そのもの」と「焼け空」を混同しない。

## 7. データの境界と信頼性

- 地形判定は山・丘・谷などを対象とする。
- ビル、マンション、樹木、看板、橋、工事中の建物は考慮しない。
- 都市部では、地形評価が良くても建物により西空が遮られる場合がある。
- 気象予報は不確実であり、値は断定ではなく期待度として扱う。
- データ取得失敗時は推測値を出さず、再試行可能なエラー状態を表示する。

## 8. 技術上の構成

```text
ブラウザ
  Google Maps / Place Autocomplete
    ↓ 緯度・経度

アプリケーションサーバー
  日没の天文計算
  Open-Meteoへの気象照会
  DEMを用いた地形遮蔽計算
  Gradient / Dramaticスコア計算
    ↓

画面
  指定地点の今日の夕焼け予報
```

APIキーを必要とするGoogle Maps Platformの呼び出しは、Googleの推奨する制限設定を行う。Open-MeteoとDEMの取得・加工は、各サービスの利用条件を実装開始時に再確認する。

## 9. 受入条件

- 日本国内の地名、施設名、住所、または地図クリックで地点を指定できる。
- 指定地点について、今日の日没時刻と見頃を表示できる。
- `Gradient` と `Dramatic` を別々の0〜100点として表示できる。
- 国土地理院DEMを使い、日没方位の地形遮蔽を三段階で表示できる。
- 建物・樹木を未考慮である旨を常に表示する。
- 予報・DEM取得に失敗したとき、誤った結果を表示しない。

## 10. 次の段階

MVPの利用結果と精度検証を踏まえ、次の順で拡張候補を評価する。

1. PLATEAUまたは他の建物高さデータによる都市部の遮蔽物評価
2. 明日・明後日の予報
3. 現在地からの候補地点探索
4. 徒歩・自転車・車の到達時間
