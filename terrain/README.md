# ローカル DEM 地形視界エンジン

国土地理院の DEM10B を、外部ストレージやデータベースを使わずにローカルで参照するための最小構成です。

## データ配置

`gsi/` は Git 管理外のローカルデータ置き場です。配布された外側 ZIP はそのまま残します。

```text
gsi/
├── 20260816184830972-001.zip  # 国土地理院から取得した配布 ZIP
└── derived/                   # 変換スクリプトが生成するファイル
    ├── index.json
    └── tiles/
        └── 533945.dem
```

配布 ZIP の内側には、2 次メッシュごとの ZIP があり、その中の GML/XML に 10m 格子の標高値が入っています。`fmdid*.xml` はメタデータであり、変換対象にはしません。

## 変換後のタイル形式

最初の版では、国土地理院の 2 次メッシュ 1 枚を 1 つの `.dem` ファイルに変換します。

- 行数: 750
- 列数: 1125
- 格納順: 北西から東へ、行を南へ進める（国土地理院の GML の並び順を維持）
- 値: 標高を 1m 単位に丸めた signed 16-bit little-endian 整数
- 欠損値: `-32768`

タイルの地理的範囲、格子間隔、行列数、欠損値、元データ名は `index.json` に保持します。座標から対象タイルと配列上の位置を直接計算できるため、標高値のソートやデータベースは不要です。

国土地理院のDEM10Bには小数第1位の値も含まれますが、有効値は1m単位です。富士山など3,276.7mを超える地点も安全に保持するため、変換後は1m単位とします。

## 段階的な実装

1. このデータ契約を固定する。
2. 配布 ZIP から `.dem` と `index.json` を生成する。
3. 緯度・経度に対応する標高を読む。
4. ローカルのコマンドから標高読取を確認する。

日没方位に沿ったレイ計算と三段階の視界判定は、上記の標高読取を検証してから追加します。

## 変換

Python 標準ライブラリだけで変換できます。外側 ZIP を展開せず、内側の ZIP と GML を 1 メッシュずつ読みます。

```bash
python3 terrain/scripts/convert_dem.py \
  gsi/20260816184830972-001.zip \
  --output gsi/derived
```

最初の動作確認では、`--limit 1` を付けて 1 メッシュだけ変換できます。

## 標高の読取

`LocalDemStore` は、座標に対応する 2 次メッシュを `index.json` から選び、バイナリ内の必要な 2 バイトだけを読みます。タイル全体や全地域のDEMをメモリに載せません。欠損値・変換対象外の地点は例外として扱い、推測値を返しません。

## ローカル照会

変換後は、外部サービスなしで任意地点の標高を確認できます。

```bash
python3 terrain/scripts/query_dem.py \
  --data gsi/derived \
  --latitude 34.75 \
  --longitude 139.00
```

成功時は標高・使用メッシュ・格子座標を JSON で出力します。範囲外または海などで標高が欠損している場合は、終了コード `2` で理由を表示します。
